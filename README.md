# Diwali Sales Analysis (Python)

An exploratory data analysis (EDA) project on Diwali sales data, uncovering 
customer buying patterns to support better business decisions.

## What I did
- Cleaned and preprocessed the raw sales dataset
- Performed exploratory data analysis using Pandas and NumPy
- Visualized customer demographics, purchase patterns, and sales trends by 
  gender, age group, state, occupation, and product category
- Identified key insights to improve customer targeting and sales strategy

## Key Insight
Married women aged 26–35 from UP, Maharashtra, and Karnataka working in IT, 
Healthcare, and Aviation are more likely to buy products from Food, Clothing, 
and Electronics categories.

## Skills used
Python, Pandas, NumPy, Matplotlib, Seaborn, Jupyter Notebook, EDA
